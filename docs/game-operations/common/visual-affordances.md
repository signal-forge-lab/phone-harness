# Common visual affordances

Reusable UI knowledge that is not specific to one game/app.

## Information / hint icon

- Evidence: `USER_CONFIRMED` (2026-08-20)
- A small `i` information icon attached to an item/card/object indicates an
  information, hint, or detail view for that object.
- When object identity, level, family, possible outputs, or other semantics are
  uncertain, prefer opening the object's `i` view before asking the operator to
  manually name the object.
- Treat this as a generic UI affordance, not as a Merge Boss-only rule. Still
  verify the resulting panel contents before assuming a particular schema.
